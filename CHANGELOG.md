# Changelog

## 1.0.0 - 2026-09-17

First stable release of Lapi Launcher.

- Keyboard-first terminal application launcher with fuzzy search, mouse support,
  desktop entries, recent applications, and optional terminal images.
- User-first layered configuration, configurable logo, and configurable Lapi
  tool button colors.
- Complete configurable theme for terminal foreground and background, status
  roles, borders, selection, header badge, Lapi buttons, and image padding.
- In-terminal theme editor opened with a right-click outside an application
  icon. It provides a palette, exact color entry, border-style selection,
  previews, reset, cancel, and user-only persistence.
- Spanish and English interface support with automatic locale detection.
- System, desktop environment, and persistent storage information.
- Context menu to pin application desktop entries to the Desktop directory or
  remove those pinned entries.
- Prebuilt `x86_64` Linux binary and Arch Linux Pacman package support.
